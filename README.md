# Exoplanet Habitability Analysis

This project presents a data-driven statistical analysis of exoplanet habitability using the NASA Exoplanet Archive (May 2026 release).

## 🔭 Overview
- Dataset: 6,278 confirmed exoplanets
- Identified 29 Potentially Habitable Candidates (PHCs)
- Focus on habitable zone constraints, planetary radius, and equilibrium temperature

## 📊 Key Features
- Habitable zone analysis (Kopparapu model)
- Fulton radius gap analysis
- Stellar metallicity correlation
- Detection bias and population trends
- Multi-dimensional visualisation of exoplanet properties

## 🛠️ Tools Used
- Python (pandas, NumPy, SciPy, Matplotlib)
- LaTeX (AASTeX style)

## 📁 Structure
- `main.tex` — full paper
- `figs/` — all figures
- `refs.bib` — bibliography
